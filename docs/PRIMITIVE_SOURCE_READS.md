# Primitive source operations and numerical reads

This extraction executes the registered all-port source capture unchanged.
It connects its native repair transactions to its actual observer-zero
numeric records. It does not substitute the shared-vertex W12 routing model,
the group-valued production engine, or a prescribed geometric neighbor rule.

From the repository root:

```sh
python -m oph_fpe.bulk.primitive_source_reads runs/primitive-source-reads.json
python -m oph_fpe.bulk.verify_primitive_source_reads_independent runs/primitive-source-reads.json --source-root .
python -m pytest -q tests/test_primitive_source_reads.py
```

The exporter runs the component and complete source drivers, checks their
repair commitments agree, and captures seven bounded cases. The verifier
imports only the standard library. It replays every repair attempt and
no-op, reconstructs the complete native event-log hash and terminal binary64
ledger, and recomputes the actual snapshot payloads and feedback port choices.
No expanded raw event tape is stored. The source manifest includes the
conservative transitive local Python import closure and package initializers.
The `revision` field records the checkout head; file hashes identify the
actual source bytes. A release capture must additionally establish equality
of those bytes with the recorded commit, as the companion OPH live bridge does.

The exact real repair algebra is a commuting family of idempotent pair
projections, with 2^(6N) distinct transition maps. The registered scheduler
saturates after visiting all 6N disjoint seams. Additional cycles cannot
transfer a value between different seams. This extends the existing
single-log antichain diagnostic to an all-word classification and an exact
read-algebra computation. It does not claim the complete primitive alphabet
is the canonical A3 constraint grammar.

With retained initial samples, one carrier can recover its twelve partner
values by subtracting its own value from twice the mean. On normalized
preparations the complete one-carrier read rank is 23. The checker also
computes the different rank of the actual two-carrier observer's sampled
payloads. Normalization can reveal an unobserved twelfth coordinate when the
other eleven are known; the tests include this exception. Balanced changes
at two hidden coordinates instead produce indistinguishable numerical
payloads and different required remote values.

Those formulas concern exact real arithmetic. The native threshold and
rounding are retained in replay, and explicit inverse-error bounds are
reported. Global source hashes and seeds are additional information, not
local numerical reads. The actual observer JSON includes a global source
root; the nonidentifiability claim does not extend to that entire JSON.

Two further controls execute the native local/observer interfaces:

- Opposite relative phases give equal initial intensities and different
  subsequent intensities under the actual twelve-port unitary. A rational
  Taylor bound certifies the gap and all 144 nonzero propagator entries at
  the exact step 1/131072. The intensity ledger therefore lacks the state
  needed for a universal recurrent update by this unitary.
- On a controlled uniform snapshot, the native feedback selects port two
  from port zero. An order-five source incidence rotation fixes the input
  and moves that output. This rule is not an equivariant protected selector.
  The control is an observer-interface input, not a claim about a particular
  initialization seed. It does not dispute covariance of the local unitary.
